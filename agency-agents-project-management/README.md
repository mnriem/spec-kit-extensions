# Agency Agents — Project Management

Project Management division specialists from the Agency Agents collection (7 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Project Management** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-project-management
```

| Command | Agent |

| `/speckit.agency-agents-project-management.studio-producer` | Studio Producer |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-project-management.experiment-tracker
```
