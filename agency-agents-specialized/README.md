# Agency Agents — Specialized

Specialized division specialists from the Agency Agents collection (53 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Specialized** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-specialized
```
