# Changelog

All notable changes to this extension will be documented in this file.

## [1.0.0] - 2026-09-23

### Added

- Initial release of twelve native Spec Kit change-management workflows
- Six core workflows: explore, propose, apply, update, sync, and archive
- Six optional workflows: new, continue, fast-forward, verify, bulk archive,
  and onboard
- Reusable proposal, specification delta, design, and task templates
- Native Python helper for change discovery, status, scaffolding, and archival
- Spec Kit command-reference tokens for portable handoffs between workflows
