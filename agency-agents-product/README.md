# Agency Agents — Product

Product division specialists from the Agency Agents collection (5 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Product** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-product
```

## Agents (5)

| Command | Agent |
|---------|-------|
| `/speckit.agency-agents-product.behavioral-nudge-engine` | Behavioral Nudge Engine |
| `/speckit.agency-agents-product.feedback-synthesizer` | Feedback Synthesizer |
| `/speckit.agency-agents-product.manager` | Product Manager |
| `/speckit.agency-agents-product.sprint-prioritizer` | Sprint Prioritizer |
| `/speckit.agency-agents-product.trend-researcher` | Trend Researcher |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-product.behavioral-nudge-engine
```
