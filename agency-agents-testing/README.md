# Agency Agents — Testing

Testing division specialists from the Agency Agents collection (8 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Testing** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-testing
```

## Agents (8)

| Command | Agent |
|---------|-------|

| `/speckit.agency-agents-testing.evidence-collector` | Evidence Collector |

| `/speckit.agency-agents-testing.tool-evaluator` | Tool Evaluator |
| `/speckit.agency-agents-testing.workflow-optimizer` | Workflow Optimizer |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-testing.accessibility-auditor
```
