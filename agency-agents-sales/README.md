# Agency Agents — Sales

Sales division specialists from the Agency Agents collection (9 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Sales** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-sales
```

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-sales.account-strategist
```
