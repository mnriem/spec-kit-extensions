# Matt Pocock Personal

Matt Pocock's personal-setup skills — editing articles and managing an Obsidian vault.

> Converted from the [`mattpocock/skills`](https://github.com/mattpocock/skills) `personal` skills. Each skill is exposed as a Spec Kit command; bundled reference files live in `resources/`.

## Installation

```bash
specify extension add mattpocock-personal
```

## Commands

| Command | Purpose |
|---------|---------|
| `/speckit.mattpocock-personal.edit-article` | Edit and improve articles by restructuring sections, improving clarity, and tightening prose. Use when user wants to edit, revise, or improve an article draft. |
| `/speckit.mattpocock-personal.obsidian-vault` | Search, create, and manage notes in the Obsidian vault with wikilinks and index notes. Use when user wants to find, create, or organize notes in Obsidian. |
