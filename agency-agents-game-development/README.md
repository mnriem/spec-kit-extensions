# Agency Agents — Game Development

Game Development division specialists from the Agency Agents collection (20 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Game Development** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-game-development
```
