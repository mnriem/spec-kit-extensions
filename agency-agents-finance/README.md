# Agency Agents — Finance

Finance division specialists from the Agency Agents collection (5 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Finance** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-finance
```

## Agents (5)

| Command | Agent |
|---------|-------|
| `/speckit.agency-agents-finance.bookkeeper-controller` | Bookkeeper & Controller |
| `/speckit.agency-agents-finance.financial-analyst` | Financial Analyst |
| `/speckit.agency-agents-finance.fpa-analyst` | FP&A Analyst |
| `/speckit.agency-agents-finance.investment-researcher` | Investment Researcher |
| `/speckit.agency-agents-finance.tax-strategist` | Tax Strategist |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-finance.bookkeeper-controller
```
