# Agency Agents — Academic

Academic division specialists from the Agency Agents collection (5 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Academic** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-academic
```

## Agents (5)

| Command | Agent |
|---------|-------|
| `/speckit.agency-agents-academic.anthropologist` | Anthropologist |
| `/speckit.agency-agents-academic.geographer` | Geographer |
| `/speckit.agency-agents-academic.historian` | Historian |
| `/speckit.agency-agents-academic.narratologist` | Narratologist |
| `/speckit.agency-agents-academic.psychologist` | Psychologist |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-academic.anthropologist
```
