# Agency Agents — Paid Media

Paid Media division specialists from the Agency Agents collection (7 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Paid Media** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-paid-media
```

## Agents (7)

| Command | Agent |
|---------|-------|
| `/speckit.agency-agents-paid-media.auditor` | Paid Media Auditor |
| `/speckit.agency-agents-paid-media.creative-strategist` | Ad Creative Strategist |
| `/speckit.agency-agents-paid-media.paid-social-strategist` | Paid Social Strategist |
| `/speckit.agency-agents-paid-media.ppc-strategist` | PPC Campaign Strategist |
| `/speckit.agency-agents-paid-media.programmatic-buyer` | Programmatic & Display Buyer |
| `/speckit.agency-agents-paid-media.search-query-analyst` | Search Query Analyst |
| `/speckit.agency-agents-paid-media.tracking-specialist` | Tracking & Measurement Specialist |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-paid-media.auditor
```
