# Agency Agents — Support

Support division specialists from the Agency Agents collection (6 agents).

> Agents in this extension are sourced from the
> [Agency Agents](https://github.com/msitarzewski/agency-agents) collection (MIT) — the **Support** division.
> Regenerate with the `agency-agents-sync` extension
> (`/speckit.agency-agents-sync.sync`).

## Installation

```bash
specify extension add agency-agents-support
```

## Agents (6)

| Command | Agent |
|---------|-------|
| `/speckit.agency-agents-support.analytics-reporter` | Analytics Reporter |
| `/speckit.agency-agents-support.executive-summary-generator` | Executive Summary Generator |
| `/speckit.agency-agents-support.finance-tracker` | Finance Tracker |
| `/speckit.agency-agents-support.infrastructure-maintainer` | Infrastructure Maintainer |
| `/speckit.agency-agents-support.legal-compliance-checker` | Legal Compliance Checker |
| `/speckit.agency-agents-support.support-responder` | Support Responder |

## Usage

Invoke any agent command to load that specialist's personality and workflow,
then describe your task:

```
/speckit.agency-agents-support.analytics-reporter
```
