# Anthropic Skills: Brand Guidelines

Applies Anthropic's official brand colors and typography to any sort of artifact that may benefit from having Anthropic's look-and-feel.

> Converted from the [`brand-guidelines`](https://github.com/anthropics/skills/tree/main/skills/brand-guidelines) agent skill (`SKILL.md`) in the [anthropics/skills](https://github.com/anthropics/skills) repository.

```bash
specify extension add anthropic-skills-brand-guidelines
```
